# DSA JavaScript Practice

This repository contains JavaScript files and HTML demos covering common data structures and algorithms, along with a few React utility examples.

- `Javascript.html`
- `Merge intervals.html`
- `backtracking.js`
- `binarySearch.js`

This workspace is used for practicing and revising:

- Arrays and searching
- Two-pointer and three-pointer patterns
- Sliding window
- Backtracking
- Merge intervals
- React utility patterns like debouncing and infinite scroll

These are learning and implementation exercises meant for personal practice and revision.
